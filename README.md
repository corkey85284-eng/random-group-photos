# Random Group Photos

Simple iPhone Progressive Web App for taking a chosen number of photos at random times within a set duration.

## How to use
1. Enable GitHub Pages (see below)
2. Open the site on iPhone Safari
3. Set number of photos and total time
4. Tap Start Camera, allow permission (rear camera for groups)
5. It takes photos at random intervals
6. Download the results or start a new session

## Enable sharing link (GitHub Pages)
1. Go to repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save
5. Wait 1-2 minutes, then visit: https://corkey85284-eng.github.io/random-group-photos/

Add to Home Screen on iPhone for app-like experience.
